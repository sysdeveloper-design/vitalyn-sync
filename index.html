Health Data Sync App

vitalyn-healthsync

vitalyn-healthsync is a health data synchronization application using Huawei Health Kit. It enables users to securely transfer their health data for personal analytics.

Purpose

The application synchronizes health data for visualization and personal insights. No medical diagnosis or treatment is provided.

Data Flow

Huawei Health App → Health Kit → vitalyn-healthsync → Secure Backend

Data Types

  • Steps
  • Distance
  • Calories
  • Heart rate
  • Sleep
  • SpO2
  • Activity records
