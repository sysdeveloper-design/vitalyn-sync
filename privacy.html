Overview Vitalyn Sync is a personal health data synchronization application. It retrieves health data from Huawei Health Kit and transmits it securely to a user-controlled backend for visualization and analysis. The application does not provide medical advice or medical diagnosis. 3. Data We Collect The application accesses the following categories of health data via Huawei Health Kit: Step count Distance and activity data Calories burned Heart rate Sleep data SpO2 (blood oxygen levels) Activity records No other personal data is intentionally collected. We do not collect: Contacts Messages Photos Location (unless explicitly enabled for activity tracking) Financial data 4. Purpose of Data Processing Health data is processed for the following purposes: Synchronization from Huawei Health Kit to the user’s personal account Visualization of health metrics Personal health tracking and analytics We do not use data for advertising, profiling, or third-party marketing. 5. Legal Basis (GDPR) We process personal data under the following legal basis: Article 6(1)(a) GDPR – User consent Article 6(1)(b) GDPR – Provision of the service requested by the user Health data is processed only after explicit user consent via Huawei Health Kit permissions. 6. Data Storage and Security All transmitted data is: Encrypted in transit using HTTPS/TLS Stored in a secure backend database Access-restricted to authenticated users only We apply appropriate technical and organizational measures to protect data against unauthorized access, alteration, or loss. 7.
