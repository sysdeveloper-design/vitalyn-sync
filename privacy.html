Privacy Policy – Vitalyn Sync

1. Data Controller

Vitalyn Sync
Contact: support@vitalyn.com

2. Overview

Vitalyn Sync is a health data synchronization application that retrieves data from Huawei Health Kit and transmits it securely to a user-controlled backend.

The application does not provide medical diagnosis or medical treatment.

3. Data Sources

Data is collected exclusively via Huawei Health Kit.

Collected data types may include:

  • Step count
  • Distance and activity data
  • Calories burned
  • Heart rate
  • Sleep data
  • SpO2 (blood oxygen)
  • Activity records

No other personal data is collected.

4. Purpose of Processing

Data is processed for:

  • Synchronization from Huawei Health Kit
  • Personal health tracking
  • Data visualization for the user

No advertising or profiling is performed.

5. Legal Basis (GDPR)

Processing is based on:

  • Article 6(1)(a) GDPR – User consent
  • Article 6(1)(b) GDPR – Service execution

Health data is only accessed after explicit user consent via Huawei Health Kit permissions.

6. Data Flow

Data flows as follows:

Huawei Health App → Huawei Health Kit → Vitalyn Sync App → Secure Backend

7. Data Storage & Security

All data is transmitted via HTTPS and stored in secure databases with restricted access.

8. Data Sharing

No data is sold or shared with third parties.

9. Data Retention

Data is stored only as long as necessary. Users can request deletion at any time.

10. User Rights (GDPR)

  • Access to data
  • Correction of data
  • Deletion of data
  • Withdrawal of consent
  • Data export

11. Children

The application is not intended for users under 16 years of age.
